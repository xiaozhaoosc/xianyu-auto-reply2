## 1. 产品愿景与定位

### 1.1 产品愿景

打造国内领先的闲鱼多账号智能运营平台，为个人卖家与团队提供**一站式**的消息自动回复、自动发货、商品管理、返佣分销解决方案。

### 1.2 产品定位

| 维度 | 现状（v1.x） | 目标（v2.0） |
|------|:--|:--|
| 产品形态 | 单机部署工具 | SaaS 平台 + 私有化部署 |
| 用户规模 | 个人用户 | 个人 + 团队 + 代理商 |
| 终端覆盖 | PC Web 管理后台 | PC + H5 + 小程序 + App |
| 扩展能力 | 硬编码规则 | 插件化规则引擎 + 开放 API |
| 商业模式 | 激活码授权 | 多租户订阅 + 代理分销 |
| 技术架构 | Python 单体 | Java 平台层 + Python 运行时引擎 |

### 1.3 核心价值主张

- **效率提升**：一条消息 3 秒内自动回复，订单 5 秒内自动发货，解放人力
- **智能运营**：AI 多模型集成，根据上下文智能回复，提升成交转化率
- **规模化管理**：一个平台管理数百个闲鱼账号，统一配置与监控
- **生态共建**：开放 API 与插件市场，第三方可开发自定义规则与 AI 策略

## 5. 非功能性需求

### 5.1 性能需求

| 指标 | 目标值 | 说明 |
|------|------|------|
| 消息处理延迟 | < 3 秒 | 从收到消息到发送回复的总耗时 |
| 自动发货延迟 | < 5 秒 | 从收到订单到完成发货的总耗时 |
| API 响应时间 (P95) | < 200ms | 管理后台接口 95 分位响应时间 |
| 并发账号数 | ≥ 500 | 单节点同时管理 500 个闲鱼账号 |
| 并发 WebSocket 连接 | ≥ 500 | 单节点同时维持 500 条闲鱼长连接 |

### 5.2 可用性需求

| 指标 | 目标值 |
|------|------|
| 系统可用性 | 99.5%（月故障时间 < 3.6 小时） |
| 数据持久性 | 99.99% |
| 故障恢复时间 (RTO) | < 30 分钟 |
| 数据恢复点 (RPO) | < 1 小时 |

### 5.3 安全需求

| 需求 | 说明 |
|------|------|
| Cookie 加密存储 | AES-256 加密，密钥与数据分离 |
| 传输加密 | 全站 HTTPS + API 接口国密 SM4 加密 |
| 认证与鉴权 | JWT + Sa-Token，支持 Token 刷新 |
| 数据脱敏 | 手机号、身份证、Cookie 等敏感信息自动脱敏 |
| 操作审计 | 所有 CUD 操作记录到审计日志 |
| 登录保护 | 失败次数限制、IP 锁定、验证码 |

### 5.4 可扩展性需求

| 需求 | 说明 |
|------|------|
| 水平扩展 | Java 服务无状态设计，支持多节点部署 |
| 插件体系 | 规则引擎支持热加载自定义规则插件 |
| 开放 API | RESTful API + gRPC，支持第三方集成 |
| 多租户 | 数据隔离，租户级配置与定制 |

## 8. 数据安全与合规需求

### 8.1 数据分类

| 数据类别 | 敏感级别 | 存储要求 | 示例 |
|------|:--:|------|------|
| 用户凭证 | 极高 | AES-256 加密 + 密钥分离 | 闲鱼 Cookie、密码 Hash |
| AI API Key | 极高 | 加密存储，脱敏展示 | OpenAI Key |
| 个人信息 | 高 | 脱敏存储，脱敏展示 | 手机号、身份证 |
| 业务数据 | 中 | 普通存储 | 商品信息、订单信息 |
| 日志数据 | 低 | 定期清理 | 操作日志、回复日志 |

### 8.2 合规要求

- 符合《网络安全法》三级等保要求（SmartAdmin 内置支持）
- 用户数据可导出、可删除（GDPR/个保法）
- Cookie 等信息仅用于代理登录，不用于其他用途
- 完整的隐私政策和用户协议

## 9. 版本规划

### Phase 1 — 基础平台（MVP，12 周）

- 基于 SmartAdmin 搭建 Java 管理后台框架
- 实现用户/角色/权限/多租户基础能力
- 迁移 54 张数据库表到 Java 层管理
- gRPC 桥接层基础框架
- PC Web 管理后台核心页面

### Phase 2 — 核心业务（14 周）

- Python 运行时引擎与 Java 平台集成
- 自动回复 + 自动发货完整流程
- 规则引擎（Drools）替代硬编码规则
- 定时任务迁移到 Quartz
- 消息日志与数据报表

### Phase 3 — 多终端 + 平台化（10 周）

- H5 移动端（UniApp）
- 微信小程序
- 开放 API v1
- 返佣系统完善
