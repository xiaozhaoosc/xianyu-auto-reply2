📌 系统总体架构与服务职责

系统基于 **FastAPI + React 18 + MySQL 8 + Redis 7 + Playwright** 微服务/多服务架构构建。全系统拆分为主网关、自动化核心、定时调度核心、共享模块和返佣推广独立系统，服务间通过轻量 HTTP 接口或 WebSocket 进行并发通信。

[已使用 Mermaid 逻辑架构渲染关系链，详见 Markdown 文档]

🛡️ 生产运维与风控防封策略

矩阵代理 IP 隔离

闲鱼对请求源 IP 极其敏感，高并发多账号会导致设备被限制。推荐在 xy_accounts 表中为每个子账号注入独立的 HTTP/Socks5 代理，Playwright 启动浏览器实例时将自动加载对应账户的专属代理，达成完美隔离。

大模型 AI 客服 & 延迟防抓

智能客服通过 AI 语义分析上下文做出回应。为规避闲鱼对自动化回复的识别，引擎注入了 3-10 秒的随机拟真延迟，并在发送时分阶段发送，规避消息秒回特征，保证账号绝对安全。
